# Wheeler Wrecker Service Homepage Mockup

A modern, responsive one-page website concept created for Wheeler Wrecker Service.

## Preview locally

Double-click `index.html`, or open the folder in VS Code and use the **Live Server** extension.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and folders from this package to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. GitHub will display the public preview URL after deployment finishes.
